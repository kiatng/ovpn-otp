## Updating

The window now checks for a new release in the background. When an update is available, disconnect and click **Update and restart**. You can also run `ovpn-otp update` from a terminal. The download is checked against the release SHA-256 file before the programs are replaced.

Versions before 0.4.0 do not have this feature. Download and unpack this release once to enable updates.

## Window

Click **Change** beside Profile to choose another `.ovpn` file. Open Details, Log, Wire and Settings from the top menu.

## Connection troubleshooting

When a server closes the connection before OpenVPN reports that the secure channel is established, the error now suggests checking the user profile and client certificate.
